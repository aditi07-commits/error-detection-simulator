# Error Detection & Correction Simulator

An interactive visual guide and simulator demonstrating four classic error detection and correction methods: **Parity Check**, **Checksum**, **CRC (Cyclic Redundancy Check)**, and **Hamming Code**.

## Live Demo
- **Live App:** https://aditi07-commits.github.io/error-detection-simulator/

## Features
- **Interactive Guide:** Flowcharts, bit diagrams, and simple explanations for each method.
- **Bit Simulator:** Test custom binary inputs or convert short words into bits, inject 1-bit, 2-bit, or burst errors, and compare how each method detects or repairs them.
